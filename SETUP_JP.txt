My Closet を Supabase に保存するための手順

このセットに含まれるもの
- app.py: Supabase PostgreSQL + Supabase Storage 対応版。DATABASE_URL を設定するとクラウドを使い、設定しない場合はローカル SQLite を使います。
- migrate_to_supabase.py: 今の closet.db とローカル写真を一度だけクラウドへコピーするためのスクリプト。
- requirements.txt: 必要な Python パッケージ。

重要
- DATABASE_URL、データベースのパスワード、SUPABASE_SERVICE_ROLE_KEY は秘密情報です。友達やチャットに送らないでください。
- このバージョンは Supabase の新しい空のプロジェクトを使う想定です。
- 移行が成功したと確認するまで、元の closet.db と private_uploads / static/uploads を削除しないでください。

1. Supabase の準備
1) Supabase で新しいプロジェクトを作成し、データベースのパスワードを安全な場所に保存します。
2) Storage の画面で新しい Bucket を作ります。名前は closet-photos、Public は OFF（非公開）にします。
3) Project Settings / API Keys でサーバー側の service_role キーを確認します。ブラウザや公開コードには入れないでください。
4) Connect を開き、Session pooler の接続文字列をコピーします。DATABASE_URL にその文字列を設定します。パスワードに記号がある場合は、URL用にエンコードが必要なことがあります。
5) Project URL と service_role キーも環境変数に設定します。

2. ファイルを置く
1) このZIP内の app.py、migrate_to_supabase.py、requirements.txt を、今の fashionista フォルダにコピーします。
2) 元の app.py は app_old.py などに名前を変えて残します。
3) PowerShell で fashionista フォルダに移動します。

3. パッケージをインストール
PowerShell で実行:
    python -m pip install -r requirements.txt

4. 環境変数を設定
次の値は自分の Supabase ダッシュボードの値に置き換えます。実際の秘密値を他人に送らないでください。

    $env:DATABASE_URL = "Supabase の Session pooler 接続文字列"
    $env:SUPABASE_URL = "Supabase の Project URL"
    $env:SUPABASE_SERVICE_ROLE_KEY = "Supabase の service_role キー"
    $env:SUPABASE_BUCKET = "closet-photos"
    $env:MY_CLOSET_SECRET = "自分で作った長くランダムな秘密文字列"

これらは今開いている PowerShell の間だけ有効です。同じ PowerShell で次の手順を進めてください。

5. 現在のデータを移行
先に migration script を実行します:
    python migrate_to_supabase.py

成功すると、アカウント・服・コーデ・評価の件数が表示されます。写真ファイルが見つからない場合は移行を停止するので、表示されたファイル名を確認してください。

6. Supabase を使って起動
    python -m py_compile app.py
    python app.py

ブラウザで http://127.0.0.1:5000 を開き、今までのアカウントと服・写真・コーデが表示されるか確認します。表示を確認するまでは元データを削除しないでください。

7. あとで Render に置くとき
Render の Environment Variables に同じ DATABASE_URL、SUPABASE_URL、SUPABASE_SERVICE_ROLE_KEY、SUPABASE_BUCKET、MY_CLOSET_SECRET を設定します。実際の値は Render の環境変数欄だけに入れてください。コードや GitHub に秘密値を直接書かないでください。

注意
- この構成では、服・コーデ・評価は Supabase PostgreSQL に、写真は Supabase Storage に保存されます。
- Supabase の無料プランには使用量の上限があり、長期間使われない無料プロジェクトは一時停止されることがあります。無料プランに自動バックアップが含まれるとは限らないため、大事なデータは定期的に別の場所にもバックアップしてください。
- Supabase 側の接続や画面をここから実際に確認することはできていません。まずは新しい空のプロジェクトで試し、成功表示とアプリ画面を確認してから次へ進んでください。
